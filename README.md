# 黄金 XAU/USD 量化交易系统 v4

基于 Python + MT4 EA 的黄金自动化交易系统。通过文件桥接实现 Python 信号分析与 MT4 交易执行的闭环。

## 架构

```
Python (信号分析)                    MT4 EA (交易执行)
┌─────────────────┐    文件桥接     ┌─────────────────┐
│ gold_runner.py  │◄──────────────►│ GoldBridge_EA   │
│ gold_trader.py  │  DWX/*.json    │                 │
│ strategies/     │                │ XAUUSD.mx 实时  │
│ sentiment/      │                │ H1/M15 K线数据  │
└─────────────────┘                └─────────────────┘
```

- **Python 端**：每30秒扫描信号，生成交易指令
- **MT4 EA**：每500ms检查指令并执行，每30秒回写K线数据
- **通信**：通过 `MQL4/Files/DWX/` 目录下的 JSON 文件

## 策略组合

> 策略的启用/禁用**只有一个开关**：`config.py` 的 `STRATEGIES[name]["enabled"]`。
> 代码里没有第二套开关（旧版曾有 `ORB_ENABLED`，与 `STRATEGIES` 不一致，导致
> 把策略设为 `False` 后仍然开单）。启动时 `gold_runner.py` 会打印**实际生效**的
> 策略清单，并告警"已启用但代码没接线"的策略。

### 1. Keltner 通道突破（H1 趋势策略）
- 突破上轨做多 / 跌破下轨做空
- ADX > 24 过滤（震荡市不交易）
- EMA100 趋势过滤（只顺大趋势方向交易）
- 11年回测：Sharpe 0.52，年化 +$119/0.01手
- 特朗普2期：Sharpe 1.47，年化 +$861/0.01手

### 2. MACD + EMA100 趋势（H1 趋势策略）
- MACD 柱状图转正做多 / 转负做空
- ADX > 24 + 价格 vs EMA100 过滤

### 3. NY 开盘区间突破 — ORB（H1 时段策略）
- 纽约开盘后第1根H1 K线的高低点作为当日区间（NY 开盘 = **UTC 14:00**）
- 突破上沿做多 / 跌破下沿做空
- 止损止盈已并入统一的**动态ATR口径**（见下节）
- 窗口有效2小时，每日只交易1次
- ⚠️ MT4 的 `iTime`/`TimeCurrent` 是**经纪商服务器时间**，不是 UTC。本机实测服务器
  为 **UTC+3**，因此 `config.MT4_SERVER_UTC_OFFSET_HOURS = 3`；填错会让 ORB 在错误的
  时间判定"纽约开盘"。

### 4. M15 RSI 均值回归（M15 低风险补充）
- RSI(2) < 15 超卖做多 / RSI(2) > 85 超买做空
- 需要 M5 强实体K线确认（依赖 EA 写出的 `bars_m5.json`）
- 不受 ADX 过滤（震荡市反而有效）

> ⚠️ **回测警示**（`research/backtest_m15rsi.py`，2024-01 → 2025-01，1283 笔）：
> 该策略**毛利为正（+$282）但净亏（-$309）** —— 一年约 1300 笔 × 每笔点差 $0.46
> ≈ $590 的成本把毛利全部吃掉。**交易频率是决定性因素**：
>
> | 最小开仓间隔 | 笔数 | 毛利$ | 点差成本$ | 净盈亏$ |
> |---|---|---|---|---|
> | 20分钟（原值/当前值） | 1283 | +282 | -590 | **-309** |
> | 60分钟 | 1222 | +214 | -562 | -348 |
> | 180分钟 | 919 | +223 | -423 | **-199** |
> | 180分钟 + 新的2.5×ATR止损 | 936 | +425 | -431 | **-6** |
>
> 结论：把 `M15_RSI_COOLDOWN_MINUTES` 从 20 改到 **180** 可把净亏收敛到基本打平；
> 若仍为负，应考虑停用该策略。**注意实盘点差是关键假设** —— 点差越小，这个策略越可能转正。

## 动态止盈止损（趋势型策略）

止损采用**结构位**，止盈保持**宽**，再加一层**很松的**保本/移动止损。

| 项目 | 规则 |
|---|---|
| 止损 | **最近的摆动低点（多）/摆动高点（空）** 外侧 + `0.3×ATR` 缓冲防插针；夹在 `0.5–2.0×ATR` |
| 止盈 | `3.0×ATR`（宽止盈，基本不触发；**不是**主要出场方式） |
| 保本/移动止损 | 浮盈 `2.0×ATR` 移到保本；`3.0×ATR` 起按 `2.0×ATR` 距离跟随；只收紧不放宽 |
| ORB 专用 | 止损取**开盘区间另一侧**（结构位），止盈同走 3.0×ATR |
| 波动率自适应 | ATR < 0.8×自身均值 → 止盈收紧至 0.8 倍；> 1.25× → 放宽 1.2 倍 |

### ⚠️ 实测结论: 止盈和跟踪**不能收紧**（这是本次回测最重要的发现）

用 `data/download/xauusd-h1-bid-*.csv`（Dukascopy H1，2015→2026）做逐根前进回测，
最近 180 天的**每笔 R 倍数**（已消除单笔风险差异，是公平比较）：

| 方案 | 每笔R | 净盈亏 | 盈亏比 |
|---|---|---|---|
| 旧：固定 2.5×ATR 止损 / 3.0×ATR 止盈 / 无跟踪 | **+0.210** | +3602 | 1.74 |
| **只把止损换成结构位**（其余同旧） | **+0.214** | +3592 | 1.69 |
| 结构止损 + 止盈 2.0×ATR + **紧**跟踪(0.6/0.8/0.4) | +0.075 | +1451 | 1.24 |
| 结构止损 + 不设硬止盈 + 紧跟踪 | +0.029 | +508 | 1.09 |
| **当前 config**：结构止损 + 3.0×ATR 止盈 + **松**跟踪(2.0/3.0/2.0) | **+0.219** | +3913 | 1.73 |

**结论**：
1. **收紧止盈有害**。"10 笔趋势单 0 笔触及止盈"是真的，但止盈没被触及**不等于**它有害 ——
   它只是不干扰趋势奔跑，真正的出场靠**时间止损**（keltner 15 小时）。把止盈从
   3.0×ATR 收到 2.0×ATR，每笔 R 从 +0.212 掉到 +0.121。
2. **紧跟踪止损有害**，且是最大杀手。`0.4×ATR`(≈$7) 的跟踪距离会被 H1 黄金的正常噪音
   反复扫掉；宽松到 `2.0×ATR` 后跟踪几乎不触发，只充当"灾难棘轮"，表现回到无跟踪水平。
3. **结构位止损本身是中性偏好**的（+0.214 vs +0.210），可以放心保留。
4. ⚠️ 注意 `DYN_TP_MAX`（止盈绝对上限）不要随手调小：旧口径的 3.0×ATR 没有绝对上限
   （实测平均 $62.9），把它卡到 $40 等于偷偷收紧止盈，每笔 R 会从 +0.212 掉到 +0.119。

**当前配置在 90/180/365 天三个窗口上每笔R均不低于旧口径，且最大回撤更小（-338 vs -413）。**
但优势幅度很小，属于噪声级别 —— 真正的价值是"没有把原来能赚钱的东西改坏"。

### 图表标注

信号触发后，Python 会通过**独立的** `annotate.json` 通道让 EA 在主图表上画出
红色箭头（信号K线）+ 止损虚线 + 止盈虚线 + 价格标签（类似 MT4 常规标注风格）。

- 标注走独立文件，**绝不占用 `commands.json`/`response.json` 下单应答通道**——
  可视化出问题不可能影响真实下单
- 对象名固定为 `GQ_<策略>_arrow|_sl|_sl_txt|_tp|_tp_txt`，因此移动止损更新时
  是**原地移动同一条线**，不会越画越多
- 清除：`bridge.clear_annotations()`（或 `CLEAR_ANNOTATIONS` 指令）

## 风控体系

| 参数 | 值 | 说明 |
|---|---|---|
| ATR 自动调仓 | 0.01–0.02 手 | 每笔风险 `RISK_PER_TRADE` = $25 |
| 止损 | 结构摆动点 + 0.3×ATR，夹在 0.5–2.0×ATR | 随结构动态变化 |
| 止盈 | 3.0×ATR（宽，基本不触发） | ⚠️ 收紧会显著降低收益 |
| 保本/移动止损 | 2.0×ATR 保本 / 3.0×ATR 起跟踪 | 宽松设置；收紧会吃掉2/3优势 |
| 最大持仓 | 3 笔 | 同策略不重复开仓，禁止反向 |
| 日内限亏 | 5 笔亏损 | 达到后停止当日交易 |
| 总止损 | $100 | 达到后系统停止 |
| 冷却期 | 1 小时 | 止损后同策略暂停开仓 |
| 方向冲突 | 禁止 | 有持仓时不开反向单 |

## 舆情分析系统

后台线程每5分钟自动采集分析，不阻塞交易扫描。

- **数据源**：Google News RSS（6个频道：黄金×2、宏观×2、特朗普×2）
- **NLP 模型**：VADER（快速）+ FinBERT（精准），双模型加权
- **经济日历**：FOMC/NFP/CPI 等60+事件，高风险事件前后自动暂停交易
- **影响方式**：暂停交易 / 方向过滤 / 仓位调整

## 数据源

优先使用 MT4 本地K线数据（EA每30秒写入），yfinance 作为 fallback。

| 来源 | 数据 | 优先级 |
|---|---|---|
| MT4 EA | XAUUSD.mx H1/M15 实时K线 | 主要 |
| yfinance | GC=F COMEX 期货 | 备用 |

## 快速开始

### 1. 环境准备
```bash
git clone https://github.com/linhuang1313/gold-quant-trading.git
cd gold-quant-trading
pip install -r requirements.txt
```

### 2. 配置
编辑 `config.py`：
- `METATRADER_DIR_PATH`：MT4 数据文件夹路径
- `SYMBOL`：交易品种名称（如 `XAUUSD.mx`）
- `CAPITAL`：本金金额

### 3. MT4 EA 安装
1. 将 `mt4_ea/GoldBridge_EA.mq4` 复制到 `MQL4/Experts/`
2. MetaEditor 打开 → F7 编译
3. 拖到 XAUUSD 图表上，勾选"允许实时交易"
4. 确认 AutoTrading 按钮为绿色

### 4. 启动
```bash
python gold_runner.py
```
